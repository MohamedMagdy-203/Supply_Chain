# Data dictionary

Generated by `scripts/build_dataset.py`. Do not edit by hand: change `src/dictionary.py`.

## weekly.parquet (one row per series per week)
| Column | Description |
|---|---|
| series_id | store_id + "__" + item_id |
| store_id, item_id, dept_id, cat_id | Hierarchy ids from M5 |
| wm_yr_wk | Walmart week id (not a counter, do not use for time arithmetic) |
| week_idx | Continuous week counter 0..N (use this for all time arithmetic) |
| week_start | Date of the first day (Saturday) of the week |
| month, week_of_year | Calendar fields of week_start |
| y | Units sold in the week (the target) |
| sell_price | Selling price in USD (empty if the item was not on sale that week) |
| on_sale | 1 if a price exists for this week, else 0 |
| snap_days | Number of SNAP days in the week (California) |
| n_events | Number of calendar events in the week |
| split | train / val / test (by target week) |

## features.parquet (one row per series per target week T)
| Column | Description |
|---|---|
| origin_week | T - 1, the last week whose sales are known |
| week_idx, wm_yr_wk | The target week T |
| y_next | Units sold in week T (the target) |
| lag_k | Units sold in week T-k |
| roll_mean_w, roll_std_w | Mean / std of units over weeks T-w ... T-1 |
| zero_share_13 | Share of zero-sales weeks in T-13 ... T-1 |
| weeks_since_sale | Weeks since the last week with sales, as known at T-1 |
| sell_price, price_change_1w, on_sale | Price of week T, its change vs week T-1, availability (known-future assumption) |
| snap_days, n_events | SNAP days and events in week T (known-future assumption) |
| month, week_of_year | Calendar fields of week T |
| history_weeks | Number of weeks of history before T |
| has_lag52 | 1 if lag_52 exists |
| store_id, dept_id, cat_id | Categorical identifiers (encode later, fit on train only) |
| split | train / val / test (by target week) |
